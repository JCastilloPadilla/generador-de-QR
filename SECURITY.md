# Seguridad

Si encuentras un fallo que pueda exponer contenido del usuario o ejecutar código no deseado,
evita publicar detalles explotables en un issue abierto.

Usa [el reporte privado de vulnerabilidades de GitHub](https://github.com/JCastilloPadilla/generador-de-QR/security/advisories/new)
si está habilitado. Si no está disponible, abre un issue sin detalles sensibles para solicitar
un canal privado de contacto.

Incluye la versión o commit afectado, el navegador, los pasos mínimos y el impacto observado.
Utiliza datos ficticios en los ejemplos. No envíes contraseñas, datos de contactos ni QR privados.

No se establece un plazo garantizado de respuesta ni un programa de recompensas.
